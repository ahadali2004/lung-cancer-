🫁 Lung Cancer Detection using MobileNetV2 (Gradio App)

This project presents a deep learning-based lung cancer detection system built using Transfer Learning with MobileNetV2. The model classifies medical images to assist in early-stage lung cancer detection, and is deployed with an interactive Gradio web interface for real-time predictions.

🚀 Features
⚡ Transfer Learning using MobileNetV2 for high accuracy and efficiency
🧠 Deep learning model trained on lung image dataset
📊 Image preprocessing & augmentation for improved performance
🌐 Gradio UI for real-time image upload and prediction
🔍 Supports quick and user-friendly cancer classification
🛠️ Tech Stack
Python
TensorFlow / Keras
MobileNetV2 (Pre-trained CNN)
Gradio
OpenCV / NumPy
📌 Use Case

This project aims to assist in early detection of lung cancer by providing an AI-powered diagnostic support tool for educational and research purposes.
